\section{Data availability}

The ModelSEED Biochemistry Database is available at
\url{https://github.com/ModelSEED/ModelSEEDDatabase} under the MIT licence, as
versioned flat files and JSON, and through the \texttt{ModelSEEDDatabase} PyPI
package. Released structures, thermodynamic values with per-source uncertainty,
evidence grades, atom mappings and the low-confidence reaction flags are all in
that repository. The scripts that regenerate every published value, including
the eQuilibrator cache rebuild, are under \file{Scripts/Thermodynamics/}.

Two dependencies are not redistributed. The digitized measured pKa
values~\cite{iupac_pka} are licensed CC-BY-NC-4.0 and are consumed by the
pipeline but not shipped, so a reader reconciling released tables against the
deposited values will find entries sourced from a file that is not present. The
eQuilibrator compound cache is a pinned public release rather than a rebuilt
artefact, which makes the protonation layer reproducible by citation but not
regenerable without a licensed tool.
