\subsection{Atom mapping and connectivity}\label{sec:results-mapping}

Atom mappings are published for 32,877 reactions, 59\% of the database
(Figure~\ref{fig:direction}C): 25,058 clean, and 7,819 that required salvage
and are tagged, because a reaction needing one repair is likely to carry others
that are not visible. Reachability analyses can use both classes;
mechanism-level tracing should filter to the clean set.

Structure-aware similarity resolves reactions expressed in different namespaces
into single equivalence classes, which is what allows a model built against one
source's identifiers to be compared with another's (Supplementary Table~S3).
