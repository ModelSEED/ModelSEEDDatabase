\subsection{Distribution and community process}\label{sec:methods-distribution}

The database is distributed as versioned flat files and JSON from the public
repository, through a PyPI package, and via a Solr endpoint. Every merge runs
continuous integration that rebuilds the database from source records and
fails on any regression in balance, structure coverage or schema conformance,
so a curation change that breaks an invariant cannot be merged. External
curation arrives as pull requests against the same checks.
